## Week 1: Express Deep Dive

### Day 1 - Express Setup
- [ ] Install Express (`npm install express`)
- [ ] Understand `package.json` and `npm init`
- [ ] Create your first Express server (replace raw `http` module with Express)
- [ ] Run it and test in browser/Postman

### Day 2 - Routing
- [ ] Learn GET, POST, PUT, DELETE routes in Express
- [ ] Learn route parameters (`/users/:id`)
- [ ] Learn query parameters (`?page=1`)
- [ ] Practice 5 different routes

### Day 3 - Middleware Basics
- [ ] Understand what middleware is (a function that runs before your route)
- [ ] Learn built-in middleware: `express.json()`
- [ ] Write your own simple custom middleware (e.g. a logger)
- [ ] Understand middleware order (`next()`)

### Day 4 - Error Handling
- [ ] Learn Express error-handling middleware (4-argument function)
- [ ] Learn try-catch in async route handlers
- [ ] Create a custom error class
- [ ] Test by intentionally throwing errors

### Day 5 - Environment Variables
- [ ] Install `dotenv`
- [ ] Create a `.env` file, learn what goes in it (ports, secrets, DB URLs)
- [ ] Confirm `.env` is in `.gitignore` (never push secrets)
- [ ] Load and use an env variable in your server

### Day 6 - Project Structure
- [ ] Learn proper folder structure: `routes/`, `controllers/`, `middleware/`
- [ ] Reorganize your code into this structure
- [ ] Understand why separation of concerns matters

### Day 7 - Revision + Mini Exercise
- [ ] Revise all Week 1 topics
- [ ] Build a small "Users CRUD" API using proper folder structure
- [ ] Push to GitHub

## Week 2: What is an API Gateway

### Day 8 - Gateway Concept
- [ ] Read/watch what an API Gateway is and why big companies use one
- [ ] Understand: gateway = single entry point that routes requests to different backend services
- [ ] Write 3-4 lines in your own words explaining it (this helps for interviews later)

### Day 9 - Reverse Proxy Concept
- [ ] Learn what a reverse proxy is
- [ ] Understand how a gateway is essentially a smart reverse proxy
- [ ] Draw a simple diagram: Client → Gateway → Service A / Service B

### Day 10 - Building a Basic Proxy
- [ ] Install `http-proxy-middleware`
- [ ] Set up a basic route in your gateway that forwards to a dummy URL
- [ ] Test that forwarding works

### Day 11 - Rate Limiting
- [ ] Learn why rate limiting matters (stop abuse/overload)
- [ ] Install `express-rate-limit`
- [ ] Add basic rate limiting to your gateway
- [ ] Test it by hitting the route repeatedly

### Day 12 - Auth Check at Gateway Level
- [ ] Understand why gateways often verify JWT tokens before forwarding requests
- [ ] Write a basic auth-check middleware (verify token exists and is valid)
- [ ] Test with a valid and invalid token

### Day 13 - Request Logging
- [ ] Install `morgan` (or write your own simple logger)
- [ ] Log every incoming request (method, path, time)
- [ ] Confirm logs show up correctly

### Day 14 - Revision
- [ ] Revise Week 2 topics
- [ ] Sketch out your actual FYP architecture on paper: which services will your gateway route to?
- [ ] Push notes to GitHub

## Week 3: Docker Basics

### Day 15 - What is Docker
- [ ] Learn what containers are and why they're used (vs virtual machines)
- [ ] Understand: "it works on my machine" problem that Docker solves

### Day 16 - Install & First Container
- [ ] Install Docker Desktop
- [ ] Run `docker run hello-world`
- [ ] Learn basic commands: `docker ps`, `docker stop`, `docker images`

### Day 17 - Writing a Dockerfile
- [ ] Learn Dockerfile instructions: `FROM`, `COPY`, `WORKDIR`, `RUN`, `CMD`
- [ ] Write a Dockerfile for your gateway app

### Day 18 - Build & Run Your Image
- [ ] Run `docker build` to build your image
- [ ] Run `docker run -p 3000:3000` to start it
- [ ] Confirm it works the same as running locally

### Day 19 - Docker Compose Basics
- [ ] Learn what `docker-compose.yml` is and why it's used for multi-container apps
- [ ] Understand services, ports, and networks in Compose

### Day 20 - Write Your First docker-compose.yml
- [ ] Write a `docker-compose.yml` with your gateway as one service
- [ ] Run `docker-compose up` and confirm it starts

### Day 21 - Revision
- [ ] Revise Week 3 topics
- [ ] Make sure your gateway runs cleanly via Docker Compose
- [ ] Push Dockerfile + docker-compose.yml to GitHub

## Week 4: Build Working Gateway + Dummy Service

### Day 22 - Plan the Dummy Service
- [ ] Decide on a simple second service (e.g. a "Hello Service" with 1-2 endpoints)
- [ ] Write down its routes on paper first

### Day 23 - Build the Dummy Service
- [ ] Create it as a separate small Express app
- [ ] Test it standalone (without gateway) first

### Day 24 - Connect Gateway to Dummy Service
- [ ] Use `http-proxy-middleware` to route gateway traffic to the dummy service
- [ ] Test that a request to the gateway correctly reaches the dummy service

### Day 25 - Add Rate Limiting + Logging
- [ ] Apply your Week 2 rate-limiting and logging middleware to this real setup
- [ ] Confirm both work end-to-end

### Day 26 - Dockerize Both Services
- [ ] Write a Dockerfile for the dummy service too
- [ ] Confirm both images build successfully

### Day 27 - Run Everything Together
- [ ] Update `docker-compose.yml` to include both gateway and dummy service
- [ ] Run `docker-compose up` and test the full flow: Client → Gateway → Dummy Service
