## Week 1: JWT Authentication Deep Dive

### Day 1 - What is JWT
- [ ] Learn JWT structure: header.payload.signature
- [ ] Understand why JWT is used for stateless authentication
- [ ] Decode a sample JWT manually at jwt.io to see what's inside

### Day 2 - Generating Tokens
- [ ] Install `jsonwebtoken` package
- [ ] Generate your first token with `jwt.sign()`
- [ ] Verify/decode it with `jwt.verify()`

### Day 3 - Password Security
- [ ] Learn why plain-text passwords are never stored
- [ ] Install `bcrypt`
- [ ] Practice hashing a password and comparing it

### Day 4 - Signup Endpoint
- [ ] Build `/signup` route: hash password, save user (simple array or basic DB for now)
- [ ] Test with Postman

### Day 5 - Login Endpoint
- [ ] Build `/login` route: verify password, generate JWT on success
- [ ] Return the token in the response

### Day 6 - Protecting Routes
- [ ] Write JWT verification middleware
- [ ] Apply it to a protected test route
- [ ] Test with valid and invalid/missing tokens

### Day 7 - Revision
- [ ] Test full flow: signup → login → access protected route
- [ ] Push to GitHub

## Week 2: Refresh Tokens + Auth Service Structure

### Day 8 - Why Refresh Tokens
- [ ] Learn why access tokens are short-lived and refresh tokens are long-lived
- [ ] Understand the security reasoning behind this split

### Day 9 - Implementing Refresh Tokens
- [ ] Generate a refresh token alongside the access token at login
- [ ] Decide where to store it (for now: simple in-memory or DB field)

### Day 10 - Refresh Endpoint
- [ ] Build `/refresh` route: accept refresh token, issue new access token
- [ ] Test the exchange flow

### Day 11 - Logout Basics
- [ ] Learn simple token invalidation approaches (blacklist or short expiry)
- [ ] Build a basic `/logout` route

### Day 12 - Structure as Standalone Service
- [ ] Move all auth code into its own separate Express app (`auth-service`)
- [ ] Run it independently on its own port, confirm it works alone

### Day 13 - Connect Behind the Gateway
- [ ] In your Month 1 Gateway, add a route that forwards `/auth/*` to the Auth service
- [ ] Test that gateway → auth service routing works

### Day 14 - Revision
- [ ] Test complete auth flow (signup/login/refresh/logout) going through the Gateway
- [ ] Push to GitHub

## Week 3: Notification Service + Inter-Service Communication

### Day 15 - Plan Notification Service

### Day 16 - Build Notification Service
